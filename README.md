# Piscord — downloads

Instaladores do **Piscord** para Windows: voz, chat e compartilhamento de tela de jogos para a galera.

## 👉 [Baixar a versão mais recente](https://github.com/aranhoso/piscord-releases/releases/latest)

Na página da versão, baixe:

- **`Piscord-Setup-X.Y.Z.exe`** — **recomendado**. Instala o app e **se atualiza sozinho** sempre que sair versão nova.
- `Piscord-Portable-X.Y.Z.exe` — versão portátil (é só abrir, não instala nada). Não se atualiza sozinha.

> O Windows pode mostrar "O Windows protegeu o computador", porque o app não tem assinatura digital: clique em **Mais informações → Executar assim mesmo**.

Os arquivos `latest.yml` e `.blockmap` de cada versão são usados pela atualização automática do app.
